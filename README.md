# 📊 Vrinda Store Data Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing **Vrinda Store sales data using Microsoft Excel** to understand sales performance, customer purchasing behavior, product trends, and order patterns.

The project includes data cleaning, preprocessing, analysis, Pivot Tables, charts, and an interactive sales dashboard to convert raw data into meaningful business insights.

---

## 🎯 Objectives

* Analyze overall sales and order performance.
* Understand customer purchasing behavior.
* Identify top-performing products and categories.
* Analyze sales based on gender and age groups.
* Identify high-performing states and regions.
* Analyze monthly sales and order trends.
* Compare sales across different channels.
* Create an interactive Excel dashboard for business insights.

---

## 🗂️ Dataset

**Dataset:** Vrinda Store Data

## 🧹 Data Cleaning & Preparation

The following data preparation steps were performed:

* Removed duplicate records.
* Checked and handled missing values.
* Standardized column formats.
* Cleaned customer and product information.
* Converted date fields into appropriate formats.
* Created useful calculated columns.
* Prepared the dataset for Pivot Table analysis.
